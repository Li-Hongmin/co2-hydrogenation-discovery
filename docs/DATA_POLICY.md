# Data policy

Raw archives larger than normal Git hosting limits remain in external research storage. GitHub contains only checksums, manifests, derived tables, extraction scripts, and analysis code.

For the current In2O3 study, the full experimental/DFT archive remains in Google Drive as a split ZIP. Any selectively extracted raw file committed later must be small, necessary for reproducibility, redistributable under the source terms, and accompanied by provenance/checksum metadata.
