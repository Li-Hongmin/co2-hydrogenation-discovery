# Raw archive manifest schema

The compact central-directory manifest should contain at least:

- `path`
- `compressed_size`
- `uncompressed_size`
- `compression_method`
- `crc32`
- `disk_start`
- `local_header_offset`
- `priority_score`

A ranked candidate table should add mechanism categories such as `reactor`, `GC_MS`, `XRD`, `In_XAS`, `Zr_XAS`, `surface`, and `DFT`. No scientific outcome values should be inferred from filenames alone.
