# Decision tree

1. **Index raw archive.** Locate S1–S4 activity, gas-switch, XAS, XRD, and DFT files.
2. **Test delayed reactivation.** If S4 converges to S1 after adequate unchanged-feed dwell, pivot to recovery kinetics.
3. **If persistent, test endpoint-matched regeneration.** If mass activity tracks independent area and intrinsic rates converge, promote morphology/path dependence.
4. **If intrinsic differences remain, test hidden chemistry.** Use surface/phase-sensitive evidence to select the DFT branch.
5. **DFT Stage 1.** H-pair thermodynamics, direct CO2 healing, H2COOH scission.
6. **Expand only on trigger.** Vacancy migration, H2 dissociation, interface models, microkinetics, or MLIP sampling require an earlier discriminating result.
