# Study 001 — Zr-doped In2O3 working-state recovery

## System

`In1.9Zr0.1O3.05` during high-pressure CO2 hydrogenation to methanol.

## Central phenomenon

Using the published transient sequence as an evidence anchor:

- S1: working reference under standard feed; mean In oxidation state about +2.9; methanol STY 0.36 g MeOH (gcat h)^-1.
- S3: after severe CO2 starvation and return to standard feed; mean In oxidation state about +2.4; STY 0.28.
- S4: after CO2-only reoxidation and return to standard feed; mean In oxidation state about +2.9; STY 0.32.

Relative to the S1→S3 loss, the S4 point estimate recovers 100% of the mean-In redox coordinate but only 50% of the lost methanol function. This is the phenomenon to explain.

## Competing explanations

1. delayed reactivation under the standard feed;
2. morphology/coherent-domain memory;
3. hidden surface chemistry: vacancy topology, hydroxylation, or surface/subsurface redistribution;
4. Zr/In redistribution or partial phase segregation;
5. measurement/line-profile uncertainty.

No one mechanism is privileged before adjudication.

## Current experimental gate

First reproduce the S1→S3→CO2-only-reoxidation sequence in independent beds and hold the recovered catalyst under unchanged standard feed until kinetic stabilization. If activity returns to at least 95% of S1 without structural reversal, stop the persistent-memory headline.

Only if a persistent deficit survives should the project compare regeneration paths at a matched operando In-XANES endpoint and ask whether morphology or area-normalized intrinsic rate remains path dependent.

## Current DFT gate

The unresolved S4/S1 mass-specific rate ratio must not be fitted by one calculated barrier. DFT is restricted to mechanism-discriminating paired calculations with explicit advance/stop thresholds: H-pair thermodynamics, direct CO2 vacancy healing, H2COOH scission, and conditionally vacancy migration or interface reconstruction.
